## 总览：你要拿到的 5 个东西

到最后，你会拥有：

| # | 东西 | 放在哪 |
|---|---|---|
| 1 | AppID | `.env.local` → `WECHAT_APPID` |
| 2 | AppSecret | `.env.local` → `WECHAT_APPSECRET` |

## 第 1 步：注册微信公众号（30 分钟）

### 1.1 选类型 = **服务号**（不是订阅号）

⚠️ **关键**：必须选**服务号**，因为：
- 只有服务号能用模板消息
- 订阅号没有 OAuth 网页授权能力

### 1.2 注册流程

1. 浏览器打开：[mp.weixin.qq.com](https://mp.weixin.qq.com)
2. 点 **"立即注册"** → 选 **"服务号"** → 选 **"企业"**
3. 填邮箱（建议用公司域名邮箱，比如 `wechat@yikai.tech`）→ 邮箱验证
4. 上传：
   - **营业执照副本**（深圳市一铠科技有限公司）
   - **法人身份证正反面**
5. **对公账户打款验证**：
   - 微信会让你**先汇 ¥1-99 随机金额**到指定账户
   - 你用公司对公账户操作汇款
   - 然后回到注册页填写汇款金额
   - 1-2 个工作日内验证完成

### 1.3 命名

**强烈推荐填**：`养房 Tend` 或 `养房助手`

⚠️ **重要**：公众号名称**一旦注册无法修改**（除非走变更流程，¥30 + 1 周），所以慎选。

## 第 2 步：微信认证（¥300/年，必须）

注册完成后，公众号是**未认证**状态，**不能用模板消息**。必须做"微信认证"：

1. 登录公众号后台 → 左侧 **"微信认证"**
2. 提交认证 → 填写公司资料 → 支付 ¥300 / 年
3. 等 7 个工作日审核

⚠️ **没有认证 → 没有模板消息 → 自动提醒功能用不了**。这是必须的成本。

## 第 3 步：拿到 AppID + AppSecret

认证通过后：

1. 登录公众号后台 → 左侧 **"设置与开发"** → **"基本配置"**
2. 你会看到：
   - **AppID**：`wxXXXXXXXXXXXXXX`（16 位字符串，**可公开**）
   - **AppSecret**：点 **"重置"** → 短信验证 → 显示一串（**绝密**）

📋 复制下来，先放到记事本，等我让你填进 `.env.local`。

## 第 4 步：配置 OAuth 授权域名

这一步告诉微信："允许这些网站调我们的 OAuth 接口"。

1. 公众号后台 → **"设置与开发"** → **"公众号设置"** → **"功能设置"**
2. 找 **"网页授权域名"** → 点 **"设置"**
3. 填入：
   ```
   baozupo.vercel.app
   ```
   （未来换正式域名后再加一行）
4. 微信会让你**下载一个验证文件**（如 `MP_verify_xxxxxxxx.txt`）→ 放到我们网站根目录
5. **告诉我**，我把这个文件加到 `public/` 文件夹
6. 然后回到微信后台点 **"提交"**，验证通过即可

## 第 5 步：申请 3 个模板消息

这是养房 Tend 推送的三种提醒。

1. 公众号后台 → **"功能"** → **"模板消息"**
2. 点 **"从模板库添加"**
3. 搜索关键字，按以下表格选模板：

### 5.1 账单到期提醒模板

- 搜索：`租金 提醒` 或 `账单 到期`
- 选一个含有 5 个字段的模板（first / property / tenant / amount / due_date / remark）
- 申请通过后会获得一个 **template_id**（如 `8gIuvFiB9eYWaP1aXjeRkz3SXR3FvNbcDw9Lvk7yc8M`）
- 复制 → 之后填 `WECHAT_TEMPLATE_BILL_DUE`

### 5.2 抄表提醒模板

- 搜索：`抄表 提醒` 或 `物业 提醒`
- 字段：first / property / meter_type / last_reading / last_date / remark
- 复制 template_id → 填 `WECHAT_TEMPLATE_METER_DUE`

### 5.3 租约到期提醒模板

- 搜索：`合同 到期` 或 `租约 到期`
- 字段：first / property / tenant / end_date / days_left / remark
- 复制 template_id → 填 `WECHAT_TEMPLATE_LEASE_EXPIRY`

⚠️ **找不到完全匹配的模板**：
- 微信模板库是预设的，字段不一定一一对应
- 退而求其次：找最接近的，告诉我你选了哪个 + 字段名清单，我改我们代码的字段映射

## 第 6 步：把所有东西汇总到 .env.local

把下面这段贴到 `K:\baozupo\.env.local` 末尾（覆盖现有的占位值）：

```env
# 微信公众号
WECHAT_APPID=wx你的真AppID
WECHAT_APPSECRET=你的真AppSecret

# 模板消息 ID
WECHAT_TEMPLATE_BILL_DUE=申请通过的真ID
WECHAT_TEMPLATE_METER_DUE=申请通过的真ID
WECHAT_TEMPLATE_LEASE_EXPIRY=申请通过的真ID
```

OAuth State Secret 和 Cron Secret 让我帮你生成，告诉我"准备好了"，我会运行：

```bash
node -e "console.log('WECHAT_OAUTH_STATE_SECRET=' + require('crypto').randomBytes(32).toString('hex'))"
node -e "console.log('CRON_SECRET=' + require('crypto').randomBytes(24).toString('hex'))"
```

把输出的两行加到 .env.local。

## 第 7 步：在 Vercel 控制台同步配置

`.env.local` 只影响本地开发。生产环境（Vercel）必须**同时配置**：

1. 浏览器打开 [vercel.com](https://vercel.com) → 选 baozupo 项目

## ❓ 常见问题

### Q：必须企业认证吗？个人公众号能用吗？

**必须企业认证**。原因：
- 模板消息接口**仅对认证服务号开放**
- 个人主体最多只能注册订阅号，没有模板消息能力

### Q：¥300/年的微信认证费可以避免吗？

**不能**。这是微信的硬性要求。但相比 Pro 月卡 ¥9.9 × 几个用户就回本了。

### Q：用户必须在微信里打开 App 才能绑定吗？

**是的**。OAuth 网页授权必须在微信浏览器里完成（拿 OpenID）。
- 桌面浏览器打开会跳转失败
- 必须用户**手机微信扫码** baozupo.vercel.app/settings 才能绑

### Q：模板消息有发送限制吗？

- 认证服务号每月 **10 万条**免费
- 超出后微信不允许花钱购买更多（要等下个月）
- 内测期 < 100 用户 × 30 提醒 = 3000 条/月，完全够

### Q：每天扫一次会不会错过实时提醒？

短期方案：每天 1 次（Vercel Hobby 免费）
中期方案：升 Vercel Pro（$20/月）支持每小时
长期方案：迁到 ECS 后用 cron 任意频率
