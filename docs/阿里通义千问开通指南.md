## 第 1 步：登录阿里云（你已有账号）

1. 打开浏览器，访问：[https://www.aliyun.com](https://www.aliyun.com)
2. 右上角点"**登录**"，用你的账号登录
3. **确认头像下方显示"企业实名"标识**（不是"个人实名"）
   - 如果还是个人实名：右上角头像 → 实名认证 → 变更实名 → 上传营业执照
   - 企业实名审核要 1-3 工作日

**✅ 成功标志**：登录后右上角能看到"**深圳市一铠科技有限公司**"字样

---

## 第 2 步：找到"百炼"控制台（这是通义千问 API 的入口）

阿里云把通义千问的 API 服务叫"**百炼**"，找入口有 2 个方法：

**方法 A（推荐，最快）**：直接访问 [https://bailian.console.aliyun.com](https://bailian.console.aliyun.com)

**方法 B（备用，万一 A 打不开）**：
1. 阿里云控制台首页（登录后默认页）
2. 顶部搜索框输入：**百炼**
3. 下拉里点"**百炼大模型服务平台**"

**✅ 成功标志**：进入一个深色背景的页面，左上角写"**百炼控制台**"

---

## 第 3 步：开通服务

1. 首次进入会弹一个"**开通服务**"或"**开始体验**"按钮，点它
2. 阅读《阿里云大模型服务协议》→ 勾选同意 → 点"**立即开通**"
3. **页面会显示"恭喜您，开通成功"**

**✅ 成功标志**：左侧菜单出现"模型广场"、"应用管理"、"API-KEY 管理"等选项

**💡 关于费用**：开通免费，只在你**调用 API 才扣费**。新用户通常有免费额度（百万级 token 试用）。

---

## 第 4 步：创建 API Key（最关键一步）

1. 左侧菜单 → 找到 **"API-KEY 管理"**（在最下方"管理"区）
   - 也可能叫 "**API-KEY**" 或 "**API Keys**"
2. 点 **"创建 API-KEY"** 或 **"创建新的 API-KEY"** 按钮
3. 弹出对话框：
   - **业务空间**：选"**默认业务空间**"
   - **API-KEY 名称**：填 `养房Tend-生产环境`
   - **描述**：可以填"养房 Tend SaaS 收款/抄表识别"
4. 点 **"确定"** 创建

**✅ 成功标志**：列表里出现一行新记录，**"API-KEY"** 列有一串 `sk-xxxxxxxxxx` 格式的字符串

---

## 第 5 步：复制 API Key 给我

1. 在新建的 API Key 这一行，点 **"查看"** 按钮（或眼睛图标）
2. 完整的 Key 会显示出来，格式形如：

   ```
   sk-1a2b3c4d5e6f7g8h9i0j1k2l3m4n5o6p
   ```

3. 点 **"复制"** 按钮，把 Key 完整复制到剪贴板

**⚠️ 重要安全提醒**：
- 这个 Key **只显示一次**！点了"复制"后请立刻保存
- 如果不小心关掉了，需要**删除重建**（旧 Key 作废）
- 这个 Key 等同于"用你公司账号花钱"的密码，**不要发给任何人**，**不要传 GitHub**

---

## 第 6 步：保存 + 告诉我

**最稳妥的存放方式**：

打开 `K:\baozupo\.env.local`（这是项目根目录的密钥文件，**不在 Git 里**），在末尾加一行：

```env

```

（把 `sk-xxx` 那一串替换成你刚才复制的真 Key）

保存后告诉我："**API Key 加到 .env.local 了**"，我就开始接入代码。

## ❓ 常见问题

### Q：通义千问、千问、Qwen、百炼、灵积都是同一个东西吗？

|名字|含义|
|---|---|
|**通义千问**（Qwen）|阿里的大模型本身（产品名）|
|**百炼**|当前的 API 控制台（你要去的地方）|
|**灵积**（DashScope）|API 后端服务（开发者用的代号）|

简单记：**控制台叫"百炼"，API 后端代号叫"DashScope"，模型本身叫"通义千问"。**

我代码里会写 `DASHSCOPE_API_KEY`，因为这是官方 SDK 的标准变量名。

---

### Q：我们用的具体是哪个模型？

`qwen-vl-max`（通义千问 视觉 大尺寸版）—— 多模态理解能力最强，对收款截图、水电表照片识别准确率高。

也可能在某些便宜场景退到 `qwen-vl-plus`（识别精度略低、单价 1/3），我会在代码里根据场景智能切换。

---

### Q：阿里云账号还是个人实名，能用吗？

可以临时用，但**强烈建议先变更为企业实名**。原因：
- 企业账号开发票更方便（用户/合作伙伴未来要发票）
- 阿里云对企业账号有更多优惠和高级权限
- 后续 ECS、OSS、备案都需要企业账号

变更步骤：阿里云右上角头像 → 实名认证 → 变更实名 → 选企业实名 → 上传营业执照 → 等 1-3 天

---

### Q：我担心 API Key 被偷怎么办？

我们的代码里：
- API Key **只放在服务器端 `.env.local`**，前端永远拿不到
- 所有调用都走我们自己的 API 路由（`/api/ai/recognize-payment`），用户浏览器只能看到我们这个 URL
- `.env.local` 在 `.gitignore` 里，不会传到 GitHub
- 阿里云控制台可以查"用量日志"，发现异常可以一键作废这个 Key 重建

---

### Q：免费额度用完后大概多少钱？

参考价格（2026 年）：
- `qwen-vl-max`：输入 ¥0.02 / 千 tokens，输出 ¥0.02 / 千 tokens
- 一次收款截图识别约消耗 800-1500 tokens（包括图片转 token + 文字输出）
- **约 ¥0.02-0.03 / 次**

按 1000 个内测用户、平均每人每月用 5 次 AI 识别算：
- 月成本 ≈ 1000 × 5 × ¥0.025 = **¥125 / 月**

完全可控，不会爆炸。
