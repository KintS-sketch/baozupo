# 🚀 养房 Tend 商业传播方案

> 主体：深圳市一铠科技有限公司
>
> 适用阶段：内测期 → 早鸟年卡 ¥69 上线 → 正式年卡 ¥99
>
> 核心原则：**零现金 CAC，让用户当我们的销售员**

---

## 💰 为什么投流不划算（先算清楚账）

| 项 | 数字 |
|---|---|
| 单用户 ARPU（年付费）| ¥69-99 |
| 假设用户生命周期 | 1.5 年 |
| 单用户 LTV | ¥100-150 |
| 小程序 / App 投流单 CAC | **¥30-100** |
| 净利润 | 0% - 70%（差到不行）|

**结论**：投流只能保本，不会赚钱。**必须走零成本传播**。

**怎么做**：

**为什么有效**：
- AI 识别 = 自然炫耀的时刻
- 房东朋友圈本来就是 "我有 X 套房" 的炫耀池
- 每个用户 = 一个免费的销售员
- 0 成本，转化率 5-10%

**实施**：Claude 写代码，1-2 天能上线

## 🥈 第二梯队（中期 · 建立壁垒）

### 4. 公众号内容运营

服务号下来后，每月推 1-2 篇深度内容：

- 租客 3 个月没交租怎么办？我的实战处理流程
- 深圳房东 2026 年个税新政解读
- AI 抄表 vs 人工抄表：我半年实测对比
- 包租公的一天：用养房 Tend 节省多少时间

公众号 = 自有流量池，不依赖平台算法。

---

### 5. 房东垂直微信群渗透

**怎么做**：

- 加入 10-20 个本地业主群、包租公社群、民宿主社群
- 不打广告，先帮人解决问题（"租客违约怎么办"、"个税怎么算"）
- 建立"懂房东、有工具、有耐心"的人设
- 自然推荐养房 Tend

**预期**：3 个月养出 50-100 个种子用户。

## 🧪 当务之急：种子用户验证

在大干营销前，先验证一件事：

> 给身边 10 个房东用养房 Tend，他们会**主动**推荐给朋友吗？

**怎么测**：

- 拉 10 个房东朋友进内测群
- 让他们用 2 周
- 看有几个 **没人提醒** 就主动发朋友圈 / 推荐朋友

**判断**：

- 如果有 ≥ 3 个 → 病毒系数 K > 0.3，可以放心做营销
- 如果只有 1-2 个 → 产品还有打磨空间，营销先按住
